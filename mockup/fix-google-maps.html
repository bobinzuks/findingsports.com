🗺️ Fix Google Maps for Finding Sports

Current Issue: The Google Maps API key in the code is a development/test key that may not work for your domain or may have exceeded its quota.

Option 1: Use Your Own Google Maps API Key (Recommended)

  1. Go to Google Cloud Console
  2. Create a new project or select an existing one
  3. Enable the Maps JavaScript API:
    • Go to "APIs & Services" → "Library"
    • Search for "Maps JavaScript API"
    • Click on it and press "Enable"
  4. Create an API Key:
    • Go to "APIs & Services" → "Credentials"
    • Click "Create Credentials" → "API Key"
    • Copy the generated API key
  5. Restrict the API Key (Important for security):
    • Click on your API key
    • Under "Application restrictions", select "HTTP referrers"
    • Add your domains: 
      http://localhost:*
https://yourdomain.com/*
https://*.yourdomain.com/*
    • Under "API restrictions", select "Restrict key"
    • Select only "Maps JavaScript API"
    • Save the changes
  6. Update the code with your API key in /mockup/js/config.js: 
    window.APP_CONFIG = {
    // Replace with your API key
    GOOGLE_MAPS_API_KEY: 'YOUR_API_KEY_HERE',
    ...
Test Your API Key

Option 2: Use Leaflet Maps (Free Alternative)

If you don't want to use Google Maps, the app automatically falls back to Leaflet with OpenStreetMap tiles.

To force Leaflet usage, edit /mockup/js/config.js:

window.APP_CONFIG = {
    GOOGLE_MAPS_API_KEY: '', // Leave empty
    ENABLE_GOOGLE_MAPS: false,
    ENABLE_LEAFLET_FALLBACK: true,
    ...
Benefits: No API key needed, completely free, no usage limits

Option 3: Quick Test with Temporary Fix

For immediate testing, you can try these temporary solutions:

  1. Clear Browser Cache: Sometimes old cached responses cause issues
  2. Use Incognito Mode: Test without extensions or cache
  3. Check Console Errors: Press F12 and look for specific error messages

Common error messages and solutions:

  • InvalidKeyMapError → You need a valid API key
  • RefererNotAllowedMapError → Add your domain to allowed referrers
  • ApiNotActivatedMapError → Enable Maps JavaScript API in Cloud Console
  • OverQuotaMapError → API key has exceeded its usage quota

⚠️ Security Note

Never commit your real Google Maps API key to a public repository. Use environment variables or configuration files that are excluded from version control.
