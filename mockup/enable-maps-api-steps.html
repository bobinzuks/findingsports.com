🗺️ Enable Google Maps API - Quick Guide

Current Status: Maps JavaScript API is NOT enabled yet. Follow these steps:

Step 1: Go to API Library

Look for one of these options in your current screen:

  • Click ENABLE APIS AND SERVICES button at the top
  • OR click "Library" in the left sidebar

Step 2: Search for Maps JavaScript API

In the search box, type: Maps JavaScript API

Click on the result that says exactly "Maps JavaScript API"

Note: Don't confuse with "Maps SDK" or other similar names

Step 3: Enable the API

Click the blue ENABLE button

Wait for it to process (usually takes 5-10 seconds)

Step 4: Create Your API Key

After enabling, you'll see options to create credentials:

  1. Click CREATE CREDENTIALS
  2. Choose "API key"
  3. Copy the key that appears (looks like: AIzaSy...)

Step 5: Secure Your Key (Important!)

Click on your new API key to edit it:

  1. Under "Application restrictions", select "HTTP referrers"
  2. Add these referrers: 
    http://localhost:*
http://127.0.0.1:*
http://localhost:8080/*
  3. Under "API restrictions", select "Restrict key"
  4. Check only "Maps JavaScript API"
  5. Click SAVE
