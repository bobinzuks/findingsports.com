# Vancouver Drop-in Sports and Open Field Games Sources

## 1. Official City/Government Sources

### Vancouver Parks & Recreation
- **Website**: https://vancouver.ca/parks-recreation-culture/recreational-activities.aspx
- **Data Format**: HTML, no public API available
- **Update Frequency**: Weekly for facility data
- **Sports Covered**: Basketball, volleyball, soccer, badminton, tennis
- **Authentication**: None for viewing, account needed for booking
- **Notes**: Drop-in schedules not available via API, must check individual community center pages

### Vancouver Open Data Portal
- **URL**: https://opendata.vancouver.ca/
- **API Documentation**: https://opendata.vancouver.ca/api/v2/console
- **Data Format**: JSON API (requires API key for large datasets)
- **Available Data**: Parks locations, facilities, washrooms, special features
- **Update Frequency**: Weekly
- **Authentication**: API key required after registration
- **Legal**: Open data license
- **Note**: Schedule data NOT available, only facility information

### ActiveNet Registration System
- **URL**: https://ca.apm.activecommunities.com/vancouver/ActiveNet_Home
- **Data Format**: Web-based system
- **Sports Covered**: All city recreation programs
- **Authentication**: Account required for registration
- **Notes**: Main registration system for Vancouver Parks & Rec

### Vancouver Community Centers (Drop-in Sports)
- **Data Format**: HTML pages, PDFs
- **Update Frequency**: Varies by center
- **Sports Covered**: Basketball, volleyball, badminton, pickleball, indoor soccer
- **Authentication**: None for viewing
- **Notes**: Each center has individual schedules, first-come first-served basis

## Legal and Scraping Considerations

1. **City of Vancouver Open Data**: Open license, API available
2. **Educational Institutions**: Check individual terms of service
3. **Social Media**: Subject to platform ToS, use official APIs where available
4. **Commercial Apps**: Use official APIs or partnerships
5. **Web Scraping**: Always check robots.txt and terms of service
6. **Privacy**: Respect user data and privacy regulations

## Recommendations for Data Collection

1. **Primary Sources**: 
   - GoodRec API (if available through partnership)
   - Vancouver Open Data Portal for facility information
   - Direct partnerships with recreation centers

2. **Manual Updates**:
   - Community center schedules (often PDF or simple HTML)
   - Educational institution schedules

3. **User-Generated**:
   - Integrate with Meetup API
   - Monitor Facebook groups (with permission)

4. **Automation Potential**:
   - Vancouver Open Data API for facilities
   - LeagueLobster feeds where available
   - App APIs through partnerships
