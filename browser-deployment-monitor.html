3. Follow the recommended fixes if any issues are found

🚨 Critical: Set JWT_SECRET in Railway

If your server is restarting continuously:

  1. Go to your Railway dashboard
  2. Click on your project
  3. Go to "Variables" tab
  4. Add: JWT_SECRET = your-secure-secret-key-here
  5. The deployment will automatically restart

🛠️ Quick Fixes

Common Railway Fixes:

1. Fix nodejs Package Name

Your nixpacks.toml has nodejs-20_x but should be nodejs_20

[phases.setup]
nixPkgs = ["nodejs_20", "python311"]

2. Set Environment Variables

Add these in Railway dashboard → Variables:

JWT_SECRET=your-secure-secret-key-here
NODE_ENV=production
CORS_ORIGIN=https://findingsports.com

3. Emergency Deployment Commands

# Force rebuild with timestamp
git commit --allow-empty -m "chore: Force Railway deployment - $(date)"
git push origin main
