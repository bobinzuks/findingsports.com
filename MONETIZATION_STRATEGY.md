## 💰 REVENUE OPTIMIZATION

### Dynamic Pricing Algorithm
```python
def calculate_game_price(venue, time, demand):
    base_price = venue.standard_rate
    
    # Time-based multipliers
    if is_peak_hour(time):
        base_price *= 1.5
    elif is_off_peak(time):
        base_price *= 0.7
    
    # Demand-based pricing
    occupancy_rate = get_venue_occupancy(venue, time)
    if occupancy_rate > 0.8:
        base_price *= 1.3
    elif occupancy_rate < 0.3:
        base_price *= 0.8
    
    # Weather adjustments
    if is_perfect_weather():
        base_price *= 1.2
    
    return round(base_price, 2)
```
